## HyperPortal 0.1.7

本版本优化拖拽离开底部热区时应用条收起的动画调度，减少回拖过程中的重复动画与布局开销。

### 应用条：优化回拖收起与快速折返

- 收起动画只在拖拽状态切换时启动，避免持续的位置更新反复重启 160ms 收起动画。
- 展开动画同样按状态切换触发；快速折返时取消旧收起动画，避免旧动画的结束回调隐藏已经重新展开的应用条。
- 应用条布局参数未变化时不再重复提交，持续位置更新不再触发相同布局的反复设置。
- 图标复原动画增加重复调用保护；手指返回应用条时取消旧复原动画，避免复原和实时放大同时修改图标。
- 应用条收起期间停止处理图标放大更新，拖拽结束时取消尚未完成的应用条与图标动画。

### 构建与发布

- 主应用版本为 `0.1.7`（versionCode 13），AES ContentCatcher 的 versionCode 更新为 `1000000051`。
- 云端按发布工作流执行手势回归测试、R8 构建、双 APK 签名校验，并保留主应用的 R8 映射文件。
- 动画修正已通过本地编译；实际帧耗时及真机手势体验仍需验证。

### 安装包

- `HyperPortal.apk`：主应用与 LSPosed 模块，云端 R8 构建。
- `AES-patched.apk`：ContentCatcher 的 AES Hook，保持未混淆。

覆盖安装后，请手动重启 SystemUI，以确保新界面代码生效并清理热重载遗留的旧监听。更新 AES 后，请手动彻底关闭并重新打开目标应用。
建议验证：拖到底部展开应用条后缓慢回拖，以及快速上下折返时的动画连续性、目标投放与取消回弹。
