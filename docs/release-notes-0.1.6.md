## HyperPortal 0.1.6

本版本集中修复拖拽归属判断与中转站拖出让位动画，均为真机验证后的行为修正。

### 中转站：修复「拖回展开后继续右移又收回」

- 根因：让位面板本身是一个会向右滑出约 110dp 的悬浮窗口，原状态机却用 `DragEvent.getX()`（窗口局部坐标）和「离开窗口」事件做判定。窗口一滑动，阈值就跟着移动；而手指继续右移时是从窗口右边缘（距屏幕右边缘仅 8dp）离开并触发 `ACTION_DRAG_EXITED`，导致刚展开的面板立刻又收回。
- 修复：把手指坐标换算成屏幕绝对坐标，统一用「距屏幕右边缘的距离」判断展开与让位，不再受窗口滑动影响。
- 展开与重新让位之间加入宽滞回（56dp / 130dp）：拖回右侧中转站区域展开后，向右靠近边缘的动作不会触发收回；只有明显拖回应用区才会重新让位。
- 保留拖拽起步保护，忽略部分固件发出的 `(0,0)` 占位事件，并统一展开/让位的状态切换与动画调用，避免状态和窗口位置不同步。

### 拖拽归属：不再劫持非传送门拖拽

- 目标应用侧的窗口级拖拽监听器、`system_server` 的拖拽开始 hook、SystemUI 的 dock 监听器均先校验 `ClipDescription` 的 MIME，只有本模块的传送门拖拽才进入光晕、倾斜和分享回退逻辑；其它 App 自己的原生拖拽保持系统默认行为。
- 中转站拖出改用独立的 `application/x-hyperportal-transferdock` 标识，避免与传送门拖拽共用标记后误触发传送门的窗口级分享回退；中转站拖出仍走原生取消回弹动画。

### 构建与发布

- 主应用版本为 `0.1.6`（versionCode 12），AES ContentCatcher 的 versionCode 更新为 `1000000050`。
- 云端仍按发布工作流执行手势回归测试、R8 构建、双 APK 签名校验，并保留主应用的 R8 映射文件。

### 安装包

- `HyperPortal.apk`：主应用与 LSPosed 模块，云端 R8 构建。
- `AES-patched.apk`：ContentCatcher 的 AES Hook，保持未混淆。

更新 AES 后，请手动彻底关闭并重新打开目标应用，使其加载新的拦截器代码。
建议真机验证：普通应用内原生拖拽不受影响；文字／图片长按拖拽与取消回弹正常；中转站卡片拖出让位、拖回展开后继续右移不再收回，明显拖回应用区可重新让位。
